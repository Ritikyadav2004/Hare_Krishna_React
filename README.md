# Hare Krishna React 🚀

Welcome! This repository is my **step-by-step React learning journey**. The topics are arranged in chronological order, with each folder covering important React concepts through practical examples.

## 📌 What's Inside

- **Core Focus:** Essential React concepts required for modern frontend development.
- **Learning Approach:** Concepts are learned and implemented through practical examples.
- **Scope:** Covers most of the important React topics needed to become job-ready in frontend development.
- **Out of Scope:** Backend, Docker, System Design, Redis, and AI/ML are not included.

## 📚 23 Projects Organized by Topics

- **Core Concepts (01-06):** React basics, `useState`, Tailwind CSS
- **Intermediate (07-12):** Conditional rendering, props, form handling
- **Advanced (13-23):** APIs, React Router, Context API, `useReducer`, Redux Toolkit

## 🔑 Key Areas Covered

- **State Management:** `useState` → `useContext` → `useReducer` → Redux Toolkit
- **Hooks:** `useState`, `useEffect`, `useCallback`, `useContext`, `useReducer`
- **APIs & Integration:** Fetch API, Axios, OpenWeatherMap, Backend connectivity
- **Routing:** React Router, multiple pages and navigation
- **Styling:** CSS, Tailwind CSS, dynamic styling
- **Core Concepts:** Props, conditional rendering, form handling, async operations, error handling

## 🧠 My Learning Journey

Learning React was challenging at first. Understanding **state, props, hooks, component communication, re-rendering, API handling, routing, and application structure** took time and practice.

I faced many bugs and confusing situations while learning, but debugging and implementing concepts myself helped me understand React much better.

This repository is a record of my journey — from learning React concepts to building with them.


**Keep Learning. Keep Building. ⚛️**
