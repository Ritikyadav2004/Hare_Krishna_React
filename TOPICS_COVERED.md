## Advanced Topics Summary

### State Management Progression:
1. **useState** - Simple State (Projects 02, 04, 05, 06)
2. **useContext** - Global State without Redux (Projects 17, 18)
3. **useReducer** - Complex State with Actions (Project 22)
4. **Redux Toolkit** - Enterprise-level State Management (Project 23)

### Hooks Used:
- `useState` - State management
- `useEffect` - Side effects & lifecycle
- `useCallback` - Performance optimization
- `useContext` - Context consumption
- `useReducer` - Complex state logic

- Fetch API (Project 16)

### UI/Styling Approaches:
